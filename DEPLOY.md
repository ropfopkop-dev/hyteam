# HYTEAM в интернете

Есть два способа пустить друзей в магазин не только из своей сети.

| | Туннель из программы | Свой VPS |
|---|---|---|
| Цена | бесплатно | аренда сервера, обычно несколько сотен ₽ в месяц |
| Ваш ПК | должен быть включён, HYTEAM запущен | можно выключать |
| Адрес | `https://….trycloudflare.com`, меняется после перезапуска | постоянный, с HTTPS |
| Размер игр | любой — большие файлы загружаются частями | любой |
| Когда подходит | поиграть сегодня, проверить | постоянный магазин для всех |

---

## Способ 1. Туннель прямо из программы

1. Запустите HYTEAM в режиме **«Свой сервер»**.
2. Откройте **Настройки → Приложение HYTEAM → Доступ из интернета → «Открыть доступ»**.
   При первом включении программа скачает `cloudflared.exe` (около 55 МБ) с официального GitHub Cloudflare.
3. Появится адрес вида `https://слово-слово-слово.trycloudflare.com` — нажмите **«Копировать»** и отправьте друзьям.
   Адрес также есть в меню значка HYTEAM в трее.
4. Друзья в программе: **«Подключиться»** → вставляют адрес.

Что важно:
- Туннель работает, пока HYTEAM открыт или свёрнут в трей. После перезапуска адрес будет новый.
- Программа включит доступ снова при следующем запуске, если вы его не закрыли.
- Туннель идёт через обычный HTTPS (TCP 443), поэтому работает и там, где провайдер режет UDP/QUIC.
- Если адрес перестал открываться — «Закрыть доступ» и «Открыть доступ» ещё раз. Подробности пишутся в `%APPDATA%\HYTEAM\tunnel.log`.

## Способ 2. Свой VPS (круглосуточно)

### Что арендовать

- Ubuntu 24.04 (подойдут 22.04 и Debian 12), 1 ядро, 1–2 ГБ памяти.
- Диск — с запасом под игры: от 30–40 ГБ.
- Любой хостинг VPS: Timeweb Cloud, Selectel, REG.RU, Beget и другие.
- Хостер выдаст **IP-адрес** и **пароль root**.

Свой домен не обязателен: скрипт сам сделает адрес вида `https://203-0-113-5.sslip.io` с настоящим HTTPS-сертификатом.

### Установка (около 5 минут)

Все команды ниже выполняются в PowerShell на вашем компьютере. Вместо `IP` подставьте адрес сервера.

**1. Соберите архив с сервером** (в папке проекта):

```bash
npm run pack-server
```

**2. Отправьте его на VPS:**

```bash
scp hyteam-server.tar.gz root@IP:/root/
```

**3. Подключитесь к VPS:**

```bash
ssh root@IP
```

**4. На VPS распакуйте архив и запустите установку:**

```bash
mkdir -p hyteam && tar -xzf hyteam-server.tar.gz -C hyteam && cd hyteam && bash deploy/install.sh
```

Скрипт поставит Node.js 24 и Caddy (сам получает HTTPS-сертификаты), настроит автозапуск и ежедневные резервные копии.
В конце он покажет адрес магазина.

**5.** Откройте этот адрес и **зарегистрируйтесь первым** — вы станете владельцем магазина.

**6.** В программе HYTEAM у вас и у друзей: **«Подключиться»** → адрес из шага 4.

### Свой домен

1. В панели регистратора домена создайте A-запись `games.ваш-домен.ru` → IP сервера.
2. Подождите 5–30 минут и выполните на VPS:

```bash
cd ~/hyteam && bash deploy/install.sh games.ваш-домен.ru
```

### Перенести текущий магазин с ПК на VPS

Если у вас уже есть игры и аккаунты:

1. Остановите локальный сервер (закройте `start.bat` / выйдите из HYTEAM через трей).
2. На VPS остановите сервер:

```bash
systemctl stop hyteam
```

3. С компьютера скопируйте данные на VPS. Если сервер запускался через `start.bat` (папка `data` проекта):

```bash
scp -r data root@IP:/root/hyteam-data
```

   Если сервер был в программе HYTEAM («Свой сервер»):

```bash
scp -r "$env:APPDATA\HYTEAM\server-data" root@IP:/root/hyteam-data
```

4. На VPS положите данные на место, верните права и запустите:

```bash
cp -r /root/hyteam-data/. /var/lib/hyteam/ && chown -R hyteam:hyteam /var/lib/hyteam && systemctl start hyteam
```

### Обновление

После изменений в коде повторите шаги 1–4 установки: база, игры и настройки сохраняются.

### Полезные команды на VPS

| Что | Команда |
|---|---|
| Состояние | `systemctl status hyteam` |
| Журнал в реальном времени | `journalctl -u hyteam -f` |
| Перезапуск | `systemctl restart hyteam` |
| Сделать пользователя админом | `hyteam-make-admin логин` |
| Резервная копия базы сейчас | `/etc/cron.daily/hyteam-backup` |

Игры из GitHub сервер проверяет каждые 5 минут. Без токена GitHub даёт 60 запросов в час, но проверки
«ничего не изменилось» в лимит не входят. Если игр с GitHub много, создайте токен на github.com
(Settings → Developer settings → Personal access tokens, без особых прав) и добавьте в `/etc/hyteam.env`:

```bash
echo "GITHUB_TOKEN=ваш_токен" >> /etc/hyteam.env && systemctl restart hyteam
```

Где что лежит:
- код — `/opt/hyteam`;
- база, файлы игр и бэкапы — `/var/lib/hyteam` (бэкапы базы в `backups/`, хранятся 7 последних);
- настройки — `/etc/hyteam.env`, после изменения: `systemctl restart hyteam`.

Файлы игр (`/var/lib/hyteam/uploads`) в ежедневный бэкап не входят — при необходимости копируйте их к себе:

```bash
scp -r root@IP:/var/lib/hyteam/uploads ./backup-uploads
```
