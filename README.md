# HYTEAM — магазин игр

Свой «Steam»: магазин, библиотека, сообщество, профили, друзья, рекомендации и модерация.
Любой зарегистрированный пользователь может загрузить игру — она появится в магазине после проверки модератором.

## Запуск

Нужен [Node.js](https://nodejs.org) версии 22.13 или новее (проверено на 24).

Двойной клик по `start.bat` — или в терминале:

```bash
npm install
npm start
```

Откройте http://localhost:3000.

**Первый зарегистрированный аккаунт становится владельцем (администратором).** Зарегистрируйтесь первым.

Демо-игры, чтобы посмотреть, как всё выглядит заполненным (по желанию):

```bash
npm run seed
```

Назначить администратора вручную: `npm run make-admin -- логин`.

## Программа для Windows

Готовый установщик: `dist/HYTEAM-Setup-1.0.0.exe` — его можно раздавать друзьям.

При первом запуске программа спросит, как работать:

- **Свой сервер** — ваш компьютер становится сервером магазина (как `start.bat`, только внутри программы).
  Друзья подключаются по адресу, который показан в «Настройки → Приложение HYTEAM».
  Если закрыть окно, сервер продолжит работать в трее; выйти — правой кнопкой по значку в трее.
- **Подключиться** — ввести адрес чужого сервера, например `192.168.1.10:3000`.

В программе игры устанавливаются как в Steam: **Установить → загрузка с прогрессом → Играть**.
Архивы (ZIP, RAR, 7z) распаковываются сами, файл запуска `.exe` находится автоматически (его можно указать вручную).
Программа считает время в игре и показывает «Обновить», когда разработчик выпускает новую версию.
Игры ставятся в `C:\Users\<вы>\HYTEAM Library` — папку можно сменить в настройках.

Данные своего сервера лежат в `%APPDATA%\HYTEAM\server-data`. Чтобы программа работала с той же базой,
что и `start.bat`, выберите папку `data` этого проекта в поле «Папка с данными сервера».

Установщик не подписан цифровой подписью, поэтому Windows может показать «Система Windows защитила ваш компьютер» —
нажмите «Подробнее» → «Выполнить в любом случае».

**Один сервер для всех.** Чтобы все, кто установит программу, сразу попадали в ваш магазин,
вшейте постоянный адрес сервера и пересоберите установщик:

```bash
npm run set-server -- https://ваш-адрес
```

```bash
npm run dist
```

Адрес должен быть постоянным: VPS из [DEPLOY.md](DEPLOY.md) или домен. Адрес trycloudflare.com меняется после перезапуска — его вшивать нельзя.
Забыли пароль админа: `npm run set-password -- логин новый_пароль` (база в папке `data`).

Разработка программы:

```bash
npm run desktop
```

Пересобрать установщик (после изменений в коде):

```bash
npm run dist
```

## Что есть

- **Магазин** — поиск, жанры, теги, сортировка, «Выбор HYTEAM», похожие игры.
- **Страница игры** — галерея скриншотов, описание, требования, отзывы со звёздами и «Полезно», обсуждения.
- **Библиотека** — как в Steam: список слева, игра справа, скачивание, отметка «вышло обновление».
- **Рекомендации** — по тегам и жанрам ваших игр, оценкам, избранному и играм друзей.
- **Сообщество** — посты с картинками, лайки, комментарии, лента друзей.
- **Профиль** — уровень и опыт, значки, статистика, активность, отзывы, друзья, фон и аватар.
- **Друзья** — заявки, поиск игроков, статус «в сети».
- **Публикация игр и программ** — файл любого размера (грузится частями с докачкой), внешняя ссылка
  или **репозиторий GitHub**: магазин берёт файл из последнего релиза, сам находит новые релизы,
  обновляет версию и «Что нового», а программа HYTEAM автоматически ставит обновление игрокам.
  Можно указать файл запуска (`game.exe`, `start.bat`) для кнопки «Играть».
- **Модерация** — очередь игр (одобрить/отклонить с причиной), жалобы, блокировки, роли, журнал действий.
- **Уведомления** — о модерации, отзывах, комментариях и заявках в друзья.
- **Коды на почту, как в Steam** — подтверждение почты при регистрации, вход по коду с новых устройств
  («Настройки → Защита аккаунта», с доверенными устройствами), восстановление пароля по коду.
  Почта (SMTP) настраивается в «Модерация → Почта»: Яндекс, Mail.ru, Gmail — нужен «пароль приложения».
  Пока почта не настроена, регистрация работает без кода.
- **Каталог программ** («Модерация → Каталог программ») — Office 2024, Blender, Photoshop, After Effects,
  Claude по прямым ссылкам и Happ, v2rayN с GitHub (обновляются сами). Файлы по прямым ссылкам
  программа HYTEAM скачивает сама, без браузера; образы .img/.iso открываются кнопкой «Открыть образ».

Правки игры обычным разработчиком отправляют её на повторную проверку. Модераторы и администратор публикуют сразу.
Все игры бесплатные — оплаты нет.

## Чтобы зашли другие люди

При запуске сервер пишет адрес «В сети: http://192.168.x.x:3000» — по нему зайдут люди из вашей сети
(Windows может спросить разрешение для брандмауэра — разрешите).

Из интернета — два способа, подробно в [DEPLOY.md](DEPLOY.md):

- **Туннель из программы** (бесплатно): «Настройки → Доступ из интернета → Открыть доступ» — получите адрес `https://….trycloudflare.com`.
- **Свой VPS** (круглосуточно): `npm run pack-server`, отправить архив на сервер и запустить `bash deploy/install.sh`.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `HOST` | `0.0.0.0` | Адрес, на котором слушать |
| `DATA_DIR` | `./data` | Где хранить базу и загруженные файлы |
| `MAX_GAME_MB` | `0` | Максимальный размер файла игры, МБ (`0` — без ограничений) |
| `GITHUB_POLL_MIN` | `5` | Как часто проверять новые релизы игр из GitHub, минут |
| `GITHUB_TOKEN` | — | Токен GitHub — поднимает лимит запросов к API (нужен, если игр из GitHub много) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` | — | Почта для кодов (вместо настройки в админке) |
| `COOKIE_SECURE` | — | `1`, если сайт работает по HTTPS |

## Где лежат данные

Всё в папке `data/`: база `hyteam.db` (SQLite) и `uploads/` (картинки и файлы игр).
Для резервной копии достаточно скопировать эту папку (лучше при остановленном сервере).

## Устройство

- `server/` — Node.js + Express, встроенный SQLite (`node:sqlite`), загрузка файлов через multer.
- `public/` — интерфейс без сборки: HTML, CSS и JS-модули.
- `desktop/` — программа для Windows на Electron: окно, экран подключения, установка и запуск игр.
